用 go 实现一个协程池

发表于2025-01-06|更新于2026-04-22|Tech
|总字数:515|阅读时长:2分钟

描述

MVP[已实现]:

  1. 固定协程/worker数量
  2. 自动领取&执行任务
  3. 支持协程池停止
  4. 支持任务提交&等待完成
  5. 支持调整任务队列长度

拓展[待添加]：

  1. 支持协程数量动态/手动调整：可以通过新旧替换的方式，先启动新的，再关闭旧的
  2. 支持任务超时：利用 context.withtimeout 实现
  3. 支持查看任务结果：将 taskFunc 用 struct 包起来，包含任务 ID 和任务结果
